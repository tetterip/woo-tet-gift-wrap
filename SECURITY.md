# Security policy

## Supported versions

Only the latest release of Tet Gift Wrap for WooCommerce gets security fixes. Sites receive it through the normal WordPress
update screen.

## Reporting a vulnerability

Please **do not open a public issue**. Email **info@ttrp.gr** with:

- the plugin version and what an attacker could do,
- steps or a proof of concept to reproduce it,
- whether you plan to publish it, and when.

You should get a reply within 3 working days. We will keep you posted while we fix it, release the fix, and
credit you in the changelog unless you prefer otherwise.

Please test only against your own WordPress install, never against a live shop you don't own.
